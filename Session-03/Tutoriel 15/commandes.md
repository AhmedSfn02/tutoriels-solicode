## 🖥️ Le cycle local complet

**$** `git status`

```text
modified: index.html
```

**$** ` git add index.html`

**$** `git commit -m "Added main title to index.html" `

```text
[main 1d2d0b8] Added the main title to index.html

1 file changed, 1 insertion(+)
```

**$** `git status`

```text
On the main branch

Nothing to validate, the working copy is clean
```

✅ **Cycle terminé**
